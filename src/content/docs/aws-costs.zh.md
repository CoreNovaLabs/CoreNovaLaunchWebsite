# 一次部署要花多少钱

CoreNova Launch 的每次部署都运行在**你自己的 AWS 账号**里。我们不收取任何费用——
你收到的唯一账单来自 AWS，为 CloudFormation 栈创建的资源计费。本页说明这些资源是什么，
以及如何让账单可预期。

## 默认栈的成本

小型有状态应用的已验证默认配置是一台 EC2 `t3.small` 实例加一块 30 GB gp3 数据卷。
按 `us-east-1` 按需计费，大致是：

| 资源 | 大致月价 |
|------|---------|
| t3.small 实例（730 小时，按需） | ~$15.2 |
| 30 GB gp3 EBS 数据卷 | ~$2.4 |
| **合计（默认配置）** | **~$18 / 月** |

每个应用的详情页以「估算成本」卡片展示该数字。数字和口径在验证时按应用注册——
前端不做任何算价，你看到的就是核对过的事实。

## 什么会让账单变高

- **实例规格。** 部署向导里可以改实例类型；已验证默认档已预选，更大的规格更贵。
- **磁盘大小。** 数据卷在部署时可选 30–500 GB，gp3 按每月每 GB 计费。
- **公网出流量。** 实例到互联网的流量由 AWS 计费，公开使用量大的应用流量费可能超过计算费。
- **区域。** 各区域价格略有差异；本站估算基于 us-east-1。

## 省钱方式

- **不用时停止实例**（EC2 控制台 → 实例状态 → 停止）。数据卷和数据在停止后保留，
  只有计算计费暂停；再次启动应用即恢复。
- **选小一档实例。** 空闲应用选更小的规格可能就够——成本与余量的权衡由你决定。
- **用完删除整个栈。** CloudFormation 删除会移除所有资源，包括数据卷。删除前先备份
  （见[升级与备份](/zh/docs/upgrading-and-backups/)）。

## 免费套餐与提醒

AWS 免费套餐（12 个月）只覆盖 `t2.micro`/`t3.micro`——已验证默认的 `t3.small`
**不在**免费范围内，从第一小时起正常计费。试验期间请直接看 AWS Billing 控制台的
预估费用，不要等月底。

精确数字请用官方 [AWS Pricing Calculator](https://calculator.aws/)。本站数字是已验证
默认配置在验证时点的估算。
